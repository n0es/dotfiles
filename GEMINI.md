# Agent instructions (Gemini CLI)

Canonical agent instructions for this repository live in Cursor project rules:

**[`.cursor/rules/dotfiles-agent.mdc`](.cursor/rules/dotfiles-agent.mdc)**

That file covers Stow layout, `install.sh`, machine-specific Hyprland (`local.conf`), known bugs, debugging on a new machine, and the expectation to commit and push unless the user says otherwise.

Open that path in the repo when using Gemini CLI or any other assistant that does not load `.cursor/rules` automatically.
